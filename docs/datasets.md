# youtube_lectures 
Длинные аудиозаписи лекций на русском языке, загруженные с YouTube

**тематика** 
Образовательный контент – лекции по различным научным и прикладным дисциплинам 

**акустические условия** 
Студийные записи (чистый звук) 
Любительские записи (фоновые шумы, эхо)
Монологи и иногда вопросы из зала или диалоги

**формат вывода** 
Dataset({
    features: ['audio', 'transcription', 'context'],
    num_rows: 7
})
колонка 'audio': {
    'array': np.ndarray,  # numpy массив с аудио-волной (длина: [num_samples])
    'sampling_rate': int  # частота дискретизации (16000 Гц)
}

**вес** 
460 Мб







# golos_farfield
Сборник, содержащий около 1200 часов русской речи из областей crowd (чтение речи) и farfield (общение с интеллектуальными устройствами)
**тематика**
Crowd-сегмент: Чтение заранее подготовленных текстов (новости, инструкции, случайные предложения)
Farfield-сегмент: Команды и диалоги с умными устройствами
Возможные темы: погода, управление умным домом, поиск информации, таймеры, напоминания
**акустические условия**
Farfield-записи: Запись с расстояния, фоновые шумы, эхо 
Crowd-записи: Чистый звук, минимум шумов
**формат вывода** 
Dataset({
    features: ['audio', 'transcription', 'context' (пустая колонка)],
    num_rows: 
})
колонка 'audio': {
    'array': np.ndarray,  # numpy массив с аудио-волной (длина: [num_samples])
    'sampling_rate': int  # частота дискретизации (16000 Гц)
}
**вес** 
1,08 Гб

# sova_rudevices
Акустический корпус из примерно 100 часов живой русской речи
**тематика** 
Взаимодействие с умными устройствами (например: "Включи свет", "Поставь будильник", "Найди рецепт", вопросы о погоде, навигации, переводе текста и т.д.)
Естественная речь: Диалоги, вопросы, спонтанные реплики с типичными для разговорной речи ошибками и паузами
**акустические условия**
Farfield-записи: Аудио, записанное с расстояния (имитация работы с умными колонками).
Фоновые шумы: бытовые звуки (TV, разговоры, шум улицы)
Эхо и реверберация (из-за отражений в помещении).
Nearfield-записи: Чистый звук (ближний микрофон, минимум помех).
**формат вывода** 
**вес** 
6.25 Гб

})
**вес** 
486 Мб
